JSON Studio本地 JSON 查看器

隐私政策

最后更新：2026 年 11 月 3 日

一句话总结：JSON Studio 不收集任何数据。所有 JSON 都只在你的浏览器里处理，不会发送到任何服务器。

一、我们收集哪些信息

没有。本扩展没有账号体系，没有统计埋点，没有广告，没有远程配置，也不包含任何第三方 SDK。

二、数据如何处理

  • 网页中的 JSON 仅在你的浏览器内解析、展示、搜索和对比，不会发送到任何服务器。
  • 本扩展的代码中不存在网络请求：没有 fetch、没有 XMLHttpRequest、没有 WebSocket。
  • 不读取或修改 Cookie，不访问浏览历史，不读取书签，不读取其他标签页。
  • 「复制」操作只写入你本机的剪贴板。
  • 展开状态、主题、搜索词都不做持久化，关闭页面即消失。

三、权限说明

权限用途
activeTab 你点击扩展图标时，读取当前标签页的文本，用于判断它是否为 JSON 并展示查看器。不点击不会读取任何页面。
scripting 将扩展包内自带的 formatter.js 注入当前标签页，渲染查看器。脚本随扩展打包，不加载远程代码。
可选的网站访问权限
http://*/*、https://*/*		 仅在你主动开启「始终自动格式化」并同意授权后，才在网页上自动运行；可随时在扩展弹窗中撤销。

四、数据共享

不共享、不出售、不转让任何数据——因为本扩展根本不收集数据。也不存在「为广告目的使用数据」或「用于信用评估」的情况。

五、第三方服务

无。本扩展不接入任何第三方统计、广告、崩溃上报或云服务。

六、数据保留

没有服务器端数据需要保留。扩展在本地也不持久化保存你查看过的 JSON 内容，页面关闭后即释放。

七、儿童隐私

本扩展不收集任何人的数据，包括儿童。

八、政策变更

如果未来版本引入需要处理数据的功能，我们会在扩展更新说明中明确告知，并同步修改本页面。

九、联系方式

如有疑问，可通过 Chrome Web Store 商品页上的支持链接联系我们，或在项目仓库提交 issue。
